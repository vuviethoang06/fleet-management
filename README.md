# Fleet Management System (Đề 30)
Website quản lý xe, bảo dưỡng, lịch trình, tài xế — Flask + PostgreSQL + pgAdmin + Nginx (HTTPS).

## Chạy nhanh
```bash
cp .env.example .env      # đổi mật khẩu
docker compose up -d --build
```
Truy cập: https://localhost (chấp nhận chứng chỉ tự ký) · pgAdmin: https://localhost/pgadmin/
